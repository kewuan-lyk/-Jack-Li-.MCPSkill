# Reusable AI Toolkit

My MCP Skill is a custom agent toolkit. This is a read-only natural English style checker skill and a FastMCP project context inspection server, built for managing homework assignments and project repositories.


# Skill Motivation
Friction: In previous assignments, I frequently had to instruct the AI to stop using overly verbose, academic "AI jargon"  and force it to stick to natural student-level English.

  > "Please stop using words like 'delve' or 'testament'. Rewrite this in simple, natural English that sounds like a regular college student wrote it."(HW4)
  > "Make the response direct and concise. Don't sound like a marketing pitch or an essay generator."(HW6)

# MCP Server Motivation
Friction: The agent often hallucinated file paths or asked me to manually dump repository trees and config files before it could assist with setup or documentation.
  > "Wait, that path doesn't exist in my project. Look at my project structure first."
  > "Here is my current package.json and repository folder setup again..."


# Overview
1. `natural-english-checker` (Skill): A read-only checker that scans text/documentation for AI jargon, overly formal structures, and passive voice. Reports findings with line numbers and simple alternatives without modifying any files.
2. `repo-context-fetcher` (MCP Server): A Python stdio server built with FastMCP that exposes a read-only tool to inspect local repository folder trees and key configuration summaries.


# Skill Installation
Copy the skill folder to your user-level or project-level Codex skills directory:
```bash
# User-level discovery directory (macOS)
cp -r .codex/skills/natural-english-checker ~/.codex/skills/


MCP Server Registration
Ensure Python dependencies are installed:

Bash
pip install -r requirements.txt
Register the server in your client configuration file (~/.codex/config.toml):

Ini, TOML
[mcp_servers.repo-context-fetcher]
command = "python"
args = ["/FULL/PATH/TO/YOUR/REPO/server.py"]  # Replace with your absolute path
(The installation steps are generated by AI to ensure accuracy)
```
